## Assignment Description

This assignment is a set of 20 Python programs that build up from basic `for` loops to a complete menu-driven application. It covers:

- `for` loops and nested loops (number analysis, tables, patterns, primes)
- Working with lists and strings without built-in helpers like `sum()`, `max()` and `min()`
- `while` loops for menu-driven programs and retry logic (ATM, calculator, guessing game)
- Writing reusable functions that return values
- Combining functions, loops and data structures in larger applications (shopping cart, bank account, student registration system)

Each question is solved in its own file, numbered in the same order as the assignment.

## Setup Instructions

1. Install **Python 3.8 or newer**. Check your version with:
   ```
   python --version
   ```
2. Unzip `python_programs.zip` and open the folder in a terminal.
3. No external libraries are needed. Every program uses only the Python standard library.

## How to Run

Run any program with:

```
python 01_number_analyzer.py
```

Replace the file name with the program you want to run. On some systems, use `python3` instead of `python`.

Programs 10, 13, 17, 19 and 20 are menu-driven and keep running until you choose the Exit option.
